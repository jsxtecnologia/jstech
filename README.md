# Js Tech - Landing Page (HTML, CSS, JavaScript Puro)

Uma landing page moderna e responsiva para a empresa Js Tech, desenvolvida utilizando apenas HTML, CSS e JavaScript puro, sem frameworks.

## 🚀 Tecnologias Utilizadas

- **HTML5** - Estrutura semântica da página
- **CSS3** - Estilização e responsividade
- **JavaScript (ES6+)** - Interatividade e dinamismo
- **Google Fonts** - Montserrat e Roboto para tipografia

## 📋 Funcionalidades

- ✅ Design responsivo para desktop, tablet e mobile
- ✅ Animações e transições suaves
- ✅ Seções organizadas: Hero, Serviços, Sobre, Contato
- ✅ Formulário de contato básico
- ✅ Navegação suave entre seções
- ✅ Otimizado para carregamento rápido

## 🛠️ Como Executar Localmente

1. **Clone ou baixe o repositório:**
   ```bash
   git clone <url-do-repositorio>
   cd js-tech-landing-pure
   ```

2. **Abra o arquivo `index.html` no seu navegador:**
   Você pode simplesmente arrastar e soltar o arquivo `index.html` para a janela do seu navegador, ou usar um servidor local simples:
   ```bash
   # Navegue até a pasta do projeto
   cd js-tech-landing-pure
   # Inicie um servidor HTTP simples (requer Python instalado)
   python3 -m http.server 8000
   ```
   Em seguida, acesse `http://localhost:8000` no seu navegador.

## 🌐 Deploy no GitHub Pages

### Método: Deploy Manual

1. **Crie um novo repositório no GitHub**
   - Acesse [GitHub.com](https://github.com)
   - Clique em "New repository"
   - Nome sugerido: `js-tech-landing-pure`
   - Marque como "Public"
   - Clique em "Create repository"

2. **Faça Upload dos Arquivos:**
   - Copie todo o conteúdo da pasta `js-tech-landing-pure/` (incluindo `index.html`, `css/`, `js/`, `assets/`) para a raiz do seu novo repositório GitHub.
   - Faça commit e push para o branch `main` (ou `gh-pages` se preferir).

3. **Configure o GitHub Pages:**
   - No seu repositório, vá em **Settings** > **Pages**
   - Em "Source", selecione **"Deploy from a branch"**
   - Escolha o branch onde você fez o upload (`main` ou `gh-pages`) e a pasta `/ (root)`
   - Clique em **Save**

4. **Aguarde o Deploy:**
   - O GitHub Pages levará alguns minutos para publicar seu site.
   - A URL será: `https://SEU_USUARIO.github.io/SEU_REPOSITORIO/` (ex: `https://seu_usuario.github.io/js-tech-landing-pure/`)
